# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately using GitHub's private
vulnerability reporting: open the repository's **Security** tab and select
**Report a vulnerability**. Do **not** open a public issue for a security
problem.

You will receive an acknowledgement within 5 business days. We will keep you
informed while the issue is triaged and fixed, and credit you for the report
if you want.

## Supported versions

Only the latest release is supported with security fixes. Please upgrade to
the newest release before reporting an issue that may already be fixed.
